# Public Website

This workspace owns public pages, same-origin submission endpoints, public
site-settings reads, and media delivery. The admin UI lives in `apps/admin`.
CMS schemas and booking services live in `packages/cms`.

Install dependencies from the repository root with `npm ci` and start both apps
with `npm run dev`. For commands, environment setup, and testing, see the
[root README](../../README.md). See [deployment.md](../../deployment.md) before
configuring hosting or custom domains.
